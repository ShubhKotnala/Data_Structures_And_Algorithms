# Contributor Covenant Code of Conduct

This project adheres to the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating, you agree to uphold this code.

## Enforcement
Report unacceptable behavior via a confidential issue or by contacting the maintainers through their GitHub profile. We will review and respond in good faith.

Portions of this Code of Conduct are adapted from the Contributor Covenant, version 2.1.
