# Security Policy

## Supported Versions
This is a learning repository; we accept reports for the currently active `main` branch.

## Reporting a Vulnerability
Please **do not** open a public issue with exploit details. Instead:
1. Open a private security advisory (GitHub → Security → Advisories), or
2. If advisories are unavailable, open an issue with the prefix **[SECURITY]** and we will coordinate a private channel.

We aim to acknowledge within 5 business days.
